## ✨ 特性

聚合搜索 · 流畅播放 · 弹幕互动 · TMDB 智能匹配 · 收藏管理 · 追剧更新 · 视频源订阅 · 观看历史 · 响应式设计 · 高性能 · 多端适配 · 出色的UI/UX

### 管理员中心

- 登录表单上方的锁图标可点击进入 `/admin/login`，维护页则通过顶部 Logo 进入，页面不显示额外页脚。该入口在维护期间仍可使用，验证为管理员后进入管理中心；管理员登录页的锁图标可返回主站，普通账号不能通过此入口绕过维护限制。
- 沿用设置中心的吸顶标签菜单，分为「站内公告」「用户管理」「操作记录」，默认显示站内公告。
- 使用与设置页一致的子路径：`/admin/announcements`、`/admin/users`、`/admin/audit`，`/admin` 默认跳转公告页。刷新和浏览器前进／后退均恢复对应模块；旧 `tab`、`view` 查询链接会重定向到新路径，保留账号详情、筛选和分页。切换模块保留账号筛选并重置分页。
- 站内公告首次打开才加载；在管理员中心切换标签时保留未保存的公告编辑，离开管理员中心或刷新后需重新编辑。

### 站内公告

- 管理员在「管理员中心」选择普通公告、维护通知或版本更新，支持填写维护时间或版本号、保存草稿、发布更新和下架。
- 点击「预览公告」查看当前编辑内容的正式弹窗样式，无需先保存；预览不会发布公告或改变已读记录。
- 新公告自动弹窗；点击「我知道了」、关闭按钮或按 Escape 后，本机当前账号不再重复弹出当前版本。顶部导航保留查看入口，发布新版本后重新提醒；播放期间延后至退出播放页再展示。
- 维护公告发布时需填写开始和结束时间：按服务器时间自动进入维护、到时恢复；访客在登录前就会看到维护页，已登录的普通用户停止播放并进入维护页，管理员始终可用。维护结束后访客恢复登录入口，已登录用户恢复访问；不再显示过期维护公告弹窗或查看入口，已打开的弹窗会自动收起。管理员仍可在公告管理中编辑、预览或重新发布。下架可提前恢复访问，维护前的公告已读状态不影响维护限制。
- 维护时间提供「现在起 30 分钟 / 1 小时 / 2 小时」快捷设置，按点击时刻同时更新开始与结束的日期和时间，确认后再发布。
- 维护类型固定显示「系统维护」，无需填写公告标题；所有类型的正文均可留空。维护页集中显示倒计时和起止时间，长说明在独立限高区域滚动，长链接自动换行；公告弹窗的标题与底部按钮保持可见。
- 维护页显示按服务器时间校准的预计恢复倒计时，每秒更新；跨天维护显示剩余天数，结束后自动恢复访问。
- 网站打开期间每分钟及回到页面、网络恢复时刷新公告；维护状态每 15 秒检查，已知的起止时间由本机依据服务器时钟定时切换。需要依次执行[公告基础迁移](supabase/migrations/202610200001_site_announcement.sql)、[公告类型升级](supabase/migrations/202610200002_announcement_types.sql)、[定时维护迁移](supabase/migrations/202610200003_scheduled_maintenance.sql)、[正文可选迁移](supabase/migrations/202610220001_optional_announcement_content.sql)和[登录前维护查询迁移](supabase/migrations/202610250001_public_maintenance_status.sql)，详见[配置指南](docs/cloud-sync.md#site-announcement)。

### 追剧更新

- 在收藏卡片点击「开启追更」，首页「追剧更新」会集中显示更新集数、待看集数和继续观看入口。
- 没有开启追更时首页自动隐藏该区域，收藏页提供开启引导；海报和剧名始终可点击，即使检查失败也能进入 TMDB 详情或 CMS 播放页。
- TMDB 剧集从实际季列表选择追更季，显示季名称并排除特别篇，默认沿用最近观看的有效季；CMS 收藏直接检查原视频源。季信息按需加载并缓存，加载失败可重试，已开启的追更保留原选择。
- 打开网站时自动检查，30 分钟内复用同配置的成功结果，也可点击「检查更新」立即刷新。
- 首页与收藏卡片支持单部「重新检查」，绕过该剧当前季的缓存，失败时保留上次成功结果。单部与批量检查共用最多 2 个并发请求的队列，不重复加入正在检查的剧集，也不会因单部重试中断其他剧集。
- 首页显示本轮「已检查 N / M 部」进度、失败数量及缓存复用数量。失败也计入已检查，复用缓存不冒充网络检查；同轮重试不重复计算剧集，下一轮重置统计。进度只存在当前页面内存中，切账号、切季或更改检查配置后重置。
- 首次成功检查建立新集基准，已有剧集只计入待看；之后同一季、同一资源出现新集时显示「新增 N 集」，首页优先展示。提醒可以标记已读，待看进度保留。完成[提醒同步迁移](docs/cloud-sync.md#cross-device-series-reminders)后，新集基准和已读收据随账号跨设备同步；离线已读保留待上传，新设备不会清掉云端未读，重新追更沿用该资源的提醒历史。不同季、绑定源和源配置指纹分别隔离。
- 首页追更列表可按「有新集」「待看」「已追平」「检查异常」筛选，并显示各类数量。标记已读或校准进度后即时更新；尚无结果、检查失败或源已停用的剧集不会计入已追平。
- TMDB 剧集当前季追平后，首页与收藏卡片会检查后续已开播的正片季，确认已看完当前季 TMDB 已知集数才显示切季提醒，避免视频源缺集时提前跳季。排除特别篇、未来季、无首播日期及空季；提醒显示首播日期，依据 TMDB 元数据，不保证视频源已经收录。切换后检查该季播放资源，原季的校准进度和固定源绑定保留。季元数据在内存缓存 1 小时，可点击「检查新季」手动刷新；CMS 收藏不做季发现。
- 集数来自视频源详情中的正片播放地址，不使用 TMDB 的计划播出集数；检查失败会保留上次成功结果。
- 首页与收藏卡片支持「绑定追更源」：选择启用的视频源，搜索并核对资源标题、年份及可用集数后确认绑定。绑定按季随收藏同步，不包含源地址或凭据；固定资源失效时可重新绑定或恢复默认选源。换源会保存当前已看集数、重新建立新集基准。
- 待看集数按连续观看进度估算，当前集看完至少 90% 才算完成。关闭观看记录或清除历史后，估算可能不完整。
- 首页追更卡片与收藏卡片支持「校准进度」：填写已看完的最后一集，或标记已追平，0 表示从头开始。校准按季保存并随收藏云同步，覆盖旧观看记录的推算，后续播放仍会自动推进；可恢复自动计算。
- 追更开关和季数随收藏云同步；检查结果与播放列表仅缓存在当前设备，提醒同步不上传源地址、代理或凭据。云端发现本机列表尚未包含的新集时，会单独刷新对应剧集。网站关闭期间不检查或推送通知。

### 弹幕系统

- 接入弹弹play 开放弹幕网络，支持自动按剧名与分集匹配全网聚合弹幕（B 站、爱奇艺、腾讯视频、优酷等多源合并）。
- 播放控制栏常驻「弹」按钮与就绪数量提示（如 `弹 (1420)`），点击展开弹幕控制面板，支持实时开关、透明度、字号、滚动速度与防重叠排版调节。
- 遇小众片名或特殊译名时，可在弹窗中手动搜索剧集并一键关联，亦支持输入 B 站 CID 直连获取或导入本地 `.xml` / `.json` 弹幕文件。
- 支持配置 `OKI_DANDAN_API_BASE_URL` 直连自建弹幕服务（如通过 Cloudflare Workers / Vercel / Docker 部署开源 [danmu_api](https://github.com/huangxd-/danmu_api)，0成本且无需凭据），或配置 `OKI_DANDAN_APP_ID` / `OKI_DANDAN_APP_SECRET` 对接弹弹play官方开放接口；未配置或无弹幕资源时静默优雅降级。
